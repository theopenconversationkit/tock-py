# Stories samples

First create python virtual env and activate it

> Warning: You must use Python 3.12; some libraries are not yet compatible with Python 3.14 (changes since Python 3.13). 

```shell
$ python3 -m venv env
$ source env/bin/activate
```

Run your T.O.C.K. stories

```shell
$ pip3 install -r requirements.txt
$ python3 webhook.py
```
